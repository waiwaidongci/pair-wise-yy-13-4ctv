# DiffScope 代码审查工作台

基于 React、TypeScript、Vite、Monaco Editor、MUI、Zustand、TanStack Query 和 React Router 的大差异审查工具。

## 运行

```bash
corepack pnpm install
corepack pnpm dev
corepack pnpm build
```

## 功能

- Monaco 提供的并排与行内 Diff 模式、语法高亮、单词级差异和虚拟滚动。
- 折叠未修改区域，F7 / Alt+↓ 快速跳转下一处修改。
- 文件树显示新增/删除行数与已查看状态。
- 任意行添加评论、回复评论、标记解决，并在编辑器中显示评论定位标记。
- mock patch 在本地生成，不依赖后端服务。

## 离线优先同步

通勤断网时的评论、回复和已查看标记不会覆盖同事在服务端的处理，而是作为**可合并的待同步操作**在本机排队，恢复联网后并入：

- **操作队列**：每次变更生成一条带幂等键（`opId`）和本机序号（`seq`）的操作，持久化在 localStorage；断网时乐观生效并标记「待同步」，恢复联网后按发生顺序（seq）推送并入。
- **幂等补传**：服务端按 `opId` 与实体 id 去重，推送中途失败可整体重试，重复补传不会多出评论；失败操作按指数退避自动重试，也可在同步中心手动重试。
- **冲突裁决**：同一行两侧都改过（本机与同事各有一条评论）时两份都保留，生成差异说明（作者、时间、内容分歧点），在审阅面板中裁决「采用本地 / 采用服务端 / 两者都保留」后定稿。
- **失效重算**：文件内容更新（版本号前进）后，该文件的已查看标记自动失效（文件树显示「内容已更新」），评论按锚定行文本重算位置，找不到锚点的评论标记「位置失效」。
- **合并规则**：服务端快照 + 本机未确认操作按序重放得到最终状态；已查看标记按文件 last-write-wins；解决/已查看的同类操作入队时合并，只保留最新一条。

### 演练

顶栏「同步中心」提供演练入口：模拟断网（通勤模式）、模拟同事变更（同一条行评论 + 解决评论 + 推送文件新版本）、下次推送失败（验证重试与幂等）。

### 代码结构

- `src/types/sync.ts` — 操作、冲突、已查看标记、服务端快照类型。
- `src/sync/merge.ts` — 客户端与服务端共用的幂等 reducer、锚点重算、冲突检测与差异说明。
- `src/sync/mockServer.ts` — 模拟服务端（独立存储）：幂等推送、快照拉取、故障注入、同事变更注入。
- `src/stores/syncStore.ts` — 待同步队列、按序冲刷、失败退避重试、冲突裁决。
- `src/stores/reviewStore.ts` — 乐观生效 + 操作入队、服务端快照合并、已查看派生。
- `src/components/SyncCenter.tsx` — 同步状态与演练入口。
